# SCF STRM no ness.know: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Importar os mapeamentos oficiais do SCF (pacote STRM 2026.1, 183 planilhas) e expor a ferramenta MCP `correlacionar`, que devolve a correspondência entre itens de frameworks diferentes, passando pelos controles SCF, com tipo de relação e força.

**Architecture:**
- **Conversão:** um script local converte as planilhas `.xlsx` num arquivo `.sql`. O administrador o aplica no D1 com `wrangler d1 execute`, então o Worker não lê Excel.
- **Dados:** três tabelas novas (`strm_frameworks`, `strm`, `scf_controles`) e um pacote `scf-strm` na tabela `pacotes`.
- **Acesso:** a chave libera o recurso marcando esse pacote, com o controle que já existe.
- **Consulta:** a ferramenta consulta em duas etapas (item de origem → controles SCF → itens de destino) e combina a força pelo elo mais fraco.

**Tech Stack:** Cloudflare Workers, D1 (SQLite), TypeScript, Vitest; `exceljs` (devDependency, só no script de conversão); `node:sqlite` (Node 22) nos testes, para rodar o SQL de verdade.

**Spec:** `docs/skills-plano.md` (skill `correlacionando-controles`) e a análise do pacote STRM 2026.1 feita em 30/10/2026, resumida em "Fatos sobre os dados".

## Fatos sobre os dados (verificados em 30/10/2026)

- **Arquivos:** são 183 `.xlsx`, nomeados `scf-strm-<região>-<framework>.xlsx`. A primeira aba sempre tem o mapeamento completo; algumas têm uma segunda aba "condensada", que deve ser ignorada.
- **Cabeçalho do arquivo:** linhas 1 a 3 trazem `Focal Document:` (o nome do framework fica na célula seguinte) e `Reference document:` (`Secure Controls Framework (SCF) version 2026.1`). O cabeçalho da tabela está na linha 5, na maioria dos arquivos.
- **Colunas variam:** devem ser localizadas pelo nome, não pela posição.
  - item: `FDE #`, `FDE#` ou `CMMC FDE#`; um arquivo tem `FDE #` repetido, e vale a primeira;
  - nome do item: `FDE Name…`;
  - relação: `STRM Relationship`;
  - controle: `SCF #`, `SCF Control` e `Secure Controls Framework (SCF) Control Description`;
  - força: `Strength of Relationship…`.

  Quebras de linha nos nomes viram espaço.
- **Relação vem com grafias diferentes:** `Equal`, `Subset Of`/`Subset of`, `Superset Of`/`superset of`, `Intersects With`/`Instersects With`/`intersects`/`Intersects With ` e `No Relationship`. `No Relationship`, `N/A` e qualquer outro valor são descartados.
- **Item:**
  - em branco nas linhas de continuação (1.097 casos), herdando o item da linha anterior;
  - às vezes numérico (2.698 casos, quase todos NIS2 e PCI), quando `1.10` vira `1.1`. Esse limite é aceito e anotado no código.
- **Anexo A da ISO 27001:** o arquivo `iso-27001-2022` só tem as cláusulas 4 a 10. Os controles do Anexo A estão no arquivo `iso-27002-2022`, com a mesma numeração (ex.: `8.16`). A ferramenta precisa dizer isso.
- **Volume:** cerca de 45 mil ligações úteis e 1.587 controles SCF.
- **Exemplo de verificação:** `iso-27002-2022 8.16` é subconjunto de `MON-01` (força 10); `nist-csf-2-0 DE.CM-01` é subconjunto de `MON-01` (força 10); `cis-csc-8-1 8.11` é igual a `MON-02.2` (força 10).

```ts
// D1 de mentira sobre node:sqlite (Node 22): os testes rodam o SQL de verdade. Sem @types/node, o módulo entra sem tipo.
interface Sqlite {
  exec(sql: string): void;
  prepare(sql: string): { all(...p: unknown[]): unknown[]; get(...p: unknown[]): unknown; run(...p: unknown[]): { changes: number } };
}
const { DatabaseSync } = (await import(/* @vite-ignore */ `node:${"sqlite"}`)) as { DatabaseSync: new (arquivo: string) => Sqlite };

export function bancoTeste(...sqls: string[]): D1Database {
  const db = new DatabaseSync(":memory:");
  for (const s of sqls) db.exec(s);
  const preparar = (sql: string, p: unknown[] = []) => ({
    bind: (...b: unknown[]) => preparar(sql, b),
    all: async () => ({ results: db.prepare(sql).all(...p) }),
    first: async () => db.prepare(sql).get(...p) ?? null,
    run: async () => ({ meta: { changes: db.prepare(sql).run(...p).changes } }),
  });
  return { prepare: (sql: string) => preparar(sql) } as unknown as D1Database;
}
```

```js
// SCF STRM (NIST IR 8477): uma planilha por framework ligando cada item a controles SCF. Funções puras, testadas em test/strm.test.ts.

const RELACOES = {
  equal: "igual",
  "subset of": "subconjunto",
  "superset of": "superconjunto",
  "intersects with": "intersecao",
  "instersects with": "intersecao", // grafia errada que existe nas planilhas
  intersects: "intersecao",
};

/** Texto de uma célula, com quebras de linha e espaços repetidos viram um espaço. */
const texto = (v) => (v == null ? "" : String(v).replace(/\s+/g, " ").trim());

/** Célula do exceljs → valor simples (rich text, fórmula, hyperlink). */
export function valor(c) {
  if (c == null || typeof c !== "object" || c instanceof Date) return c ?? null;
  if (Array.isArray(c.richText)) return c.richText.map((t) => t.text).join("");
  return c.result ?? c.text ?? null;
}

/** Linhas de uma planilha (primeira aba) → framework e ligações item × controle SCF. */
export function lerPlanilha(linhas, arquivo) {
  const topo = linhas.slice(0, 4);
  const depois = (rotulo) => {
    for (const r of topo) {
      const i = r.findIndex((c) => texto(c).replace(/:$/, "") === rotulo);
      if (i >= 0) return texto(r[i + 1]);
    }
    return "";
  };
  const id = arquivo.replace(/^scf-strm-/, "").replace(/\.xlsx$/, "");
  const nome = depois("Focal Document") || id;
  const versao = depois("Reference document").match(/version\s+(\S+)/i)?.[1] ?? null;

  const h = linhas.findIndex((r) => r.some((c) => texto(c) === "SCF #"));
  if (h < 0) return { id, nome, versao, ligacoes: [] };
  const cab = linhas[h].map(texto);
  const col = (teste) => cab.findIndex(teste);
  const c = {
    item: col((t) => /FDE ?#$/.test(t)), // primeira: há arquivo com "FDE #" repetido
    nome: col((t) => t.startsWith("FDE Name")),
    relacao: col((t) => t === "STRM Relationship"),
    scf: col((t) => t === "SCF #"),
    scfNome: col((t) => t === "SCF Control"),
    scfDescricao: col((t) => t.startsWith("Secure Controls Framework (SCF)")),
    forca: col((t) => t.startsWith("Strength of Relationship")),
  };

  const ligacoes = [];
  let item = "";
  let itemNome = null;
  for (const r of linhas.slice(h + 1)) {
    // shortcut: item numérico (ex.: "1.10" no NIS2) chega como número e perde o zero final; para corrigir, ler o formato da célula.
    if (texto(r[c.item])) {
      item = texto(r[c.item]);
      const n = texto(r[c.nome]);
      itemNome = n && n !== "N/A" ? n : null;
    }
    const relacao = RELACOES[texto(r[c.relacao]).toLowerCase()];
    const scf = texto(r[c.scf]);
    if (!item || !relacao || !/^[A-Z]{3}-\d/.test(scf)) continue;
    const f = texto(r[c.forca]);
    ligacoes.push({ item, itemNome, relacao, forca: f !== "" && Number.isFinite(Number(f)) ? Number(f) : null, scf, scfNome: texto(r[c.scfNome]), scfDescricao: texto(r[c.scfDescricao]) });
  }
  return { id, nome, versao, ligacoes };
}

const q = (v) => (v == null ? "NULL" : typeof v === "number" ? String(v) : `'${String(v).replace(/'/g, "''")}'`);
const LOTE = 200; // linhas por INSERT: bem abaixo do limite de 100 KB por instrução do D1

const INSTRUCOES =
  "Correspondência oficial entre frameworks (SCF STRM, NIST IR 8477). Use a ferramenta correlacionar. Igual ou subconjunto com força alta indica cobertura; interseção indica cobertura parcial. Confirme o requisito no texto da norma com buscar_conhecimento antes de afirmar conformidade. Controles do Anexo A da ISO 27001 estão no framework da ISO 27002 (mesma numeração).";

/** SQL idempotente: apaga e recarrega tudo, e cria ou atualiza o pacote scf-strm. */
export function paraSql(planilhas) {
  const versao = planilhas.find((p) => p.versao)?.versao ?? null;
  const sql = ["DELETE FROM strm;", "DELETE FROM strm_frameworks;", "DELETE FROM scf_controles;"];
  const controles = new Map();
  for (const p of planilhas) {
    sql.push(`INSERT INTO strm_frameworks (id, nome, versao_scf, itens) VALUES (${q(p.id)}, ${q(p.nome)}, ${q(p.versao)}, ${new Set(p.ligacoes.map((l) => l.item)).size});`);
    for (let i = 0; i < p.ligacoes.length; i += LOTE) {
      const valores = p.ligacoes.slice(i, i + LOTE).map((l) => `(${q(p.id)}, ${q(l.item)}, ${q(l.itemNome)}, ${q(l.relacao)}, ${q(l.forca)}, ${q(l.scf)})`);
      sql.push(`INSERT INTO strm (framework, item, item_nome, relacao, forca, scf) VALUES ${valores.join(", ")};`);
    }
    for (const l of p.ligacoes) if (!controles.has(l.scf)) controles.set(l.scf, l);
  }
  const lista = [...controles.values()];
  for (let i = 0; i < lista.length; i += 50) {
    sql.push(`INSERT INTO scf_controles (scf, nome, descricao) VALUES ${lista.slice(i, i + 50).map((l) => `(${q(l.scf)}, ${q(l.scfNome)}, ${q(l.scfDescricao)})`).join(", ")};`);
  }
  sql.push(
    `INSERT INTO pacotes (slug, nome, descricao, instrucoes, versao) VALUES ('scf-strm', 'Correspondência entre frameworks', ${q(`SCF STRM ${versao ?? ""}: ${planilhas.length} frameworks mapeados ao Secure Controls Framework`)}, ${q(INSTRUCOES)}, ${q(versao)}) ON CONFLICT (slug) DO UPDATE SET nome = excluded.nome, descricao = excluded.descricao, instrucoes = excluded.instrucoes, versao = excluded.versao, atualizado_em = datetime('now');`,
  );
  return sql.join("\n");
}
```

```js
#!/usr/bin/env node
// Converte o pacote STRM do SCF (pasta com os scf-strm-*.xlsx) em SQL para o D1.
//
// Uso: node scripts/strm-para-sql.mjs <pasta-dos-xlsx> <saida.sql>
// Depois: npx wrangler d1 execute ness-know --remote --file=<saida.sql>
// O SQL apaga e recarrega tudo: rodar de novo com uma versão nova do SCF substitui a anterior.
import { readdir, writeFile } from "node:fs/promises";
import { join } from "node:path";
import ExcelJS from "exceljs";
import { lerPlanilha, paraSql, valor } from "./strm.mjs";

const [pasta, saida] = process.argv.slice(2);
if (!pasta || !saida) {
  console.error("uso: node scripts/strm-para-sql.mjs <pasta-dos-xlsx> <saida.sql>");
  process.exit(1);
}
const arquivos = (await readdir(pasta)).filter((f) => /^scf-strm-.+\.xlsx$/i.test(f)).sort();
if (!arquivos.length) {
  console.error(`nenhum scf-strm-*.xlsx em ${pasta}`);
  process.exit(1);
}
const planilhas = [];
for (const f of arquivos) {
  const wb = new ExcelJS.Workbook();
  await wb.xlsx.readFile(join(pasta, f));
  const ws = wb.worksheets[0]; // a segunda aba ("condensed") repete o conteúdo
  const linhas = [];
  ws.eachRow({ includeEmpty: true }, (row) => linhas.push(Array.from({ length: row.cellCount }, (_, i) => valor(row.getCell(i + 1).value))));
  const p = lerPlanilha(linhas, f);
  if (!p.ligacoes.length) console.warn(`aviso: ${f} sem ligações (cabeçalho não reconhecido?)`);
  planilhas.push(p);
}
await writeFile(saida, paraSql(planilhas), "utf8");
const total = planilhas.reduce((n, p) => n + p.ligacoes.length, 0);
const controles = new Set(planilhas.flatMap((p) => p.ligacoes.map((l) => l.scf))).size;
console.log(`${planilhas.length} frameworks, ${total} ligações, ${controles} controles SCF, versão ${planilhas.find((p) => p.versao)?.versao ?? "?"} → ${saida}`);
```

- [ ] **Step 2: Implementar `src/strm.ts`**

```ts
// Correspondência entre frameworks pelo SCF STRM (NIST IR 8477): item de origem → controles SCF → itens dos destinos.
export const PACOTE_STRM = "scf-strm";
/** Destinos por chamada: mantém a resposta legível e a consulta pequena. */
export const MAX_DESTINOS = 10;

export interface Correspondencia {
  framework: string;
  item: string;
  nome: string | null;
  /** Controle SCF que liga origem e destino. */
  via: string;
  relacao_origem: string;
  relacao_destino: string;
  /** Elo mais fraco do caminho (0 a 10); null quando a planilha não informa. */
  forca: number | null;
}
export interface Resultado {
  origem: { framework: string; nome: string; item: string; item_nome: string | null };
  versao_scf: string | null;
  scf: { scf: string; nome: string | null; relacao: string; forca: number | null }[];
  correspondencias: Correspondencia[];
}

type Linha = { framework: string; item: string; item_nome: string | null; relacao: string; forca: number | null; scf: string };
const minimo = (a: number | null, b: number | null) => (a == null || b == null ? null : Math.min(a, b));

export async function correlacionar(db: D1Database, itemPedido: string, de: string, para: string[]): Promise<Resultado | { erro: string }> {
  const item = itemPedido.trim();
  let origem: Resultado["origem"];
  let versao: string | null = null;
  let ligacoes: { scf: string; relacao: string; forca: number | null }[];

  if (de === "scf") {
    const c = await db.prepare("SELECT scf, nome FROM scf_controles WHERE lower(scf) = lower(?)").bind(item).first<{ scf: string; nome: string | null }>();
    if (!c) return { erro: `controle SCF desconhecido: ${item}` };
    origem = { framework: "scf", nome: "Secure Controls Framework", item: c.scf, item_nome: c.nome };
    ligacoes = [{ scf: c.scf, relacao: "igual", forca: 10 }];
  } else {
    const fw = await db.prepare("SELECT nome, versao_scf FROM strm_frameworks WHERE id = ?").bind(de).first<{ nome: string; versao_scf: string | null }>();
    if (!fw) return { erro: `framework desconhecido: ${de}. Os ids estão em listar_pacotes, pacote ${PACOTE_STRM}` };
    const r = await db.prepare("SELECT framework, item, item_nome, relacao, forca, scf FROM strm WHERE framework = ? AND lower(item) = lower(?) ORDER BY forca DESC, scf").bind(de, item).all<Linha>();
    if (!r.results.length) return { erro: `item ${item} sem correspondência em ${de}. Para o Anexo A da ISO 27001, use o framework da ISO 27002 (mesma numeração)` };
    origem = { framework: de, nome: fw.nome, item: r.results[0].item, item_nome: r.results[0].item_nome };
    versao = fw.versao_scf;
    ligacoes = r.results.map((x) => ({ scf: x.scf, relacao: x.relacao, forca: x.forca }));
  }

  const nomes = new Map(
    (await db.prepare(`SELECT scf, nome FROM scf_controles WHERE scf IN (${ligacoes.map(() => "?").join(", ")})`).bind(...ligacoes.map((l) => l.scf)).all<{ scf: string; nome: string | null }>()).results.map((x) => [x.scf, x.nome]),
  );
  const scf = ligacoes.map((l) => ({ scf: l.scf, nome: nomes.get(l.scf) ?? null, relacao: l.relacao, forca: l.forca }));

  const destinos = [...new Set(para)].filter((p) => p !== de).slice(0, MAX_DESTINOS);
  if (!destinos.length) return { origem, versao_scf: versao, scf, correspondencias: [] };
  const alvo = await db
    .prepare(`SELECT framework, item, item_nome, relacao, forca, scf FROM strm WHERE scf IN (${ligacoes.map(() => "?").join(", ")}) AND framework IN (${destinos.map(() => "?").join(", ")})`)
    .bind(...ligacoes.map((l) => l.scf), ...destinos)
    .all<Linha>();

  // Um resultado por item de destino: o caminho de maior força (o elo mais fraco de cada caminho decide).
  const melhor = new Map<string, Correspondencia>();
  for (const t of alvo.results) {
    for (const o of ligacoes.filter((l) => l.scf === t.scf)) {
      const c: Correspondencia = { framework: t.framework, item: t.item, nome: t.item_nome, via: t.scf, relacao_origem: o.relacao, relacao_destino: t.relacao, forca: minimo(o.forca, t.forca) };
      const chave = `${t.framework}|${t.item}`;
      const atual = melhor.get(chave);
      if (!atual || (c.forca ?? -1) > (atual.forca ?? -1)) melhor.set(chave, c);
    }
  }
  const correspondencias = [...melhor.values()].sort((a, b) => (b.forca ?? -1) - (a.forca ?? -1) || a.framework.localeCompare(b.framework) || a.item.localeCompare(b.item, undefined, { numeric: true }));
  return { origem, versao_scf: versao, scf, correspondencias };
}
```
