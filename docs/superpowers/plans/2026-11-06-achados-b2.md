# Achados da medição da B2: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corrigir os três achados da medição da skill `avaliando-mudanca` (06/11/2026): citação sem fonte vinda do exemplo das instruções do pacote, buscas de continuação que o modelo não faz e lista de fontes que mistura o recuperado com o usado.

**Architecture:** (1) O texto das instruções do pacote `gestao-servicos-ti` é corrigido pela API de admin, com um script pequeno e testado. (2) A skill passa a declarar `buscas` (consultas de continuação) numa coluna própria; `obter_skill` as devolve e a busca prévia do faBRAINzio as executa no código e junta os trechos. (3) A resposta do faBRAINzio separa as fontes citadas no texto das apenas consultadas.

**Tech Stack:** Cloudflare Workers, D1, TypeScript, vitest (`node:sqlite`), Node 22 para os scripts.

**Spec:** `docs/projeto-ciclo-2.md` (frente B) e `skills/avaliando-mudanca/casos.md` (resultado de 06/11/2026).

## Global Constraints

- Português do Brasil, direto; marcas da ness. em caixa baixa.
- Conteúdo não mora no código: instruções de pacote e skills entram pela API de admin. Nenhuma escrita direta no D1 de produção.
- O código decide, o modelo redige. Somente leitura para os agentes.
- D1: no máximo 100 variáveis por consulta. Corpo de skill: até 4.000 caracteres.
- `npm test && npm run check` verdes em cada repositório; sem merge e sem deploy por conta própria; branch `ccr-4d9339a0-31h965` sem force push; PRs como rascunho.

## Contrato entre os repositórios

`obter_skill` (ness.know) passa a devolver, além de `nome`, `descricao`, `versao`, `corpo` e `fonte`, o campo **`buscas: string[]`** (lista de consultas; `[]` quando a skill não declara). O faBRAINzio trata a ausência do campo como `[]`, para os dois lados poderem ser publicados em qualquer ordem.

## File Structure

ness.know: `migrations/0008_skills_buscas.sql` (coluna), `src/skills.ts` (validação), `src/admin.ts` e `src/mcp.ts` (gravar e devolver), `scripts/skills-md.mjs` (ler `buscas:` do frontmatter), `skills/avaliando-mudanca/SKILL.md` (declara as buscas), `scripts/atualizar-instrucoes.mjs` (instruções de pacote), `docs/instrucoes/gestao-servicos-ti.md` (cópia de referência), docs.
faBRAINzio: `src/know.ts` (devolve as buscas da skill escolhida), `src/previa.ts` (executa as buscas e junta os trechos), `src/worker.ts` e `public/app.js` (fontes citadas e consultadas), testes.
